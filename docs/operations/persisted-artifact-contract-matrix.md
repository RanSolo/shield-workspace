# Persisted artifact contract matrix

This matrix records the persisted contracts introduced by the #242 mission
evidence tools, #243 Feature Flight preflight tools, #244 Feature Flight
control tools, and #245 Feature Flight convergence tools. All artifacts are non-authoritative and use
`authority:none` semantics. “Reject” means fail closed; no predecessor is
silently upgraded.

only. They are not authority records, provenance records, execution
attestations, signatures, or human acceptance decisions.
